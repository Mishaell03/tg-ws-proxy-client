# TG WS Proxy Android

Android-клиент для **tg-ws-proxy** с современным интерфейсом на Flutter.

Проект основан на оригинальном **tg-ws-proxy**, разработанном **Flowseal**, и адаптирован для полноценной работы на Android.

Помимо мобильного интерфейса, проект включает изменения, необходимые для запуска прокси внутри Android-приложения, интеграции с жизненным циклом системы и повышения стабильности соединения.

> **Оригинальный проект:**  
> https://github.com/Flowseal/tg-ws-proxy
>
> Огромная благодарность **Flowseal** за создание и развитие оригинального проекта.

---

# Возможности

- Современный интерфейс на Flutter
- Запуск и остановка прокси одним нажатием
- Полное управление настройками tg-ws-proxy
- Быстрое копирование MTProto-ссылки
- Подключение Telegram по одному нажатию
- Просмотр логов прокси
- Перезапуск прокси без закрытия приложения
- Встроенный Python Runtime
- Интеграция оригинального tg-ws-proxy
- Адаптация прокси для Android
- Повышенная стабильность работы на мобильных устройствах

# Архитектура

```
Flutter UI
        │
        ▼
Android (Kotlin)
        │
        ▼
Python Proxy Runtime
        │
        ▼
Modified tg-ws-proxy
        │
        ▼
Telegram
```

Приложение использует оригинальную реализацию **tg-ws-proxy** в качестве основы.

Для корректной работы на Android были реализованы изменения, связанные с запуском Python внутри приложения, управлением процессом, хранением конфигурации и стабильностью соединения.

---

# Почему отдельный проект?

Оригинальный **tg-ws-proxy** ориентирован на настольные операционные системы.

Цель данного проекта — предоставить удобный Android-клиент с современным интерфейсом, сохранив совместимость с оригинальной реализацией прокси.
